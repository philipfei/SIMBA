# Historical examples

Files in `historical/` were generated before the SIMBA reorganization. They are
read-only historical reference material, not current validation or approval.
`route.json` is **historical_unverifiable** (`missing_registration_hash`).
It cannot be used for a current four-panel comparison, even if coordinates match.
Generate a new single-map preview with `modules/coverage/preview.py`.
The preserved images compare historical runs and must not be cited as current results.
